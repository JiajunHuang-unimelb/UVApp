# UVApp

An Android app that shows the local UV index and a personal sun-protection countdown.

## Status

Early setup. The Android code is not scaffolded yet. See `PLAN.md` for the full plan (initial version, feel free to edit), many parts to be discussed and modified.

## Data sources

- Weather data from Open-Meteo.com (CC-BY 4.0).
- Place names from Nominatim and OpenStreetMap contributors.
